## 🌟 What is this?

**N_everMin_d** is a cinematic web experience built with Firebase, HTML/CSS, and expressive JavaScript.  
It’s not just a login page — it’s a mood, a memory, a moment.

- 🔥 Firebase Hosting + Auth
- 🎭 Role-based admin logic
- 🌗 Toggleable light/dark mode
- 🎨 Animated quotes and genre-driven design
- 📂 GitHub-integrated auto-deployment
